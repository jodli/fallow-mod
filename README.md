# Fallow: Tally's Last Count

A story mod for Factorio: Space Age, currently in the design phase. You crash on Nauvis next to a wrecked ship whose AI, Tally, has lost its memory. You repair it piece by piece and carry a sealed container from planet to planet to find out what it is.

**Read the story:** <https://jodli.github.io/fallow-mod/> (a draft, shared for feedback)

## What's in this repo

- [`docs/story.md`](docs/story.md): the full story, written to be read like a book. It is published as the GitHub Pages site.
- [`docs/design/game-design-document.md`](docs/design/game-design-document.md): the current design decisions and open questions.
- [`docs/design/story-brainstorm.md`](docs/design/story-brainstorm.md): how the story was developed, with its decisions and alternatives.
- [`docs/design/prior-art-research.md`](docs/design/prior-art-research.md): existing mods with cross-planet production chains, and the design space that is still open.
- [`docs/design/mod-portal-readme.md`](docs/design/mod-portal-readme.md): a draft of the description for the Factorio mod portal.

There is no mod code yet.

## Publishing the story

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) publishes the story to GitHub Pages on every push to `main` that changes `docs/`.
